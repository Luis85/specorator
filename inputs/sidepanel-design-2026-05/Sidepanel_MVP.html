# Specorator — Agent Panel
Design Brief · v1 · May 2026 · Status: In progress
## Problem
Builders writing software specs switch constantly between their notes,
code, and AI tools. There is no single surface that holds the full
context of a feature — from idea to merged PR.
## User Goal
A Cursor-like AI workflow, native inside Obsidian — scoped to spec
writing, with human approval gates before any vault write or commit.
## Design Principles
1. Trust-first — confirm before every file write, commit, or PR
2. Transparent — streaming step log shows exactly what the agent is doing
3. Scoped — agent is focused on one feature at a time
## Scope · Increment 1
→ AI chat with vault file context (@ and Attach)
→ Context tab: add, remove, browse vault files
↳ Streaming step log, Tasks, Session — deferred
## Open Questions
OQ-1 · Should the agent auto-detect feature scope? → Yes ✓
OQ-2 · How do we handle context drift across sessions? → Proposal needed
