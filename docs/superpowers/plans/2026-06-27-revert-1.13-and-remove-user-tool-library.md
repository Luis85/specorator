# Revert 1.13 settings migration & remove user tool library — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the settings UI on shipping Obsidian (≤1.12.x) by reverting the premature 1.13 deprecation migration, and fully delete the user tool library feature (kills the `Function`-constructor marketplace Error).

**Architecture:** Two independent workstreams on one branch.
- **WS1 — Revert 1.13 (commit `a14924c`, version-coupled bits only).** `minAppVersion` 1.13.0 → **1.11.5** is the headline fix: Obsidian refuses to load a plugin whose `minAppVersion` exceeds the installed app, which is why the *entire* settings tab vanished. Also restore `setWarning`/`setDynamicTooltip`/direct `display()` and pin the `obsidian` typings back to 1.12.x so those APIs type-check. **Keep** the non-version-coupled quality bits from the same commit (type-assertion generics, `check:css` ratchet, `useUnknownInCatchVariables`). The marketplace bot will re-list `setWarning`/`setDynamicTooltip`/`display` as non-blocking Warnings/Recommendations — accepted until 1.13 ships.
- **WS2 — Remove user tool library.** Delete `src/features/tools/**`, its tests, i18n, views/commands/ribbon/nav, the in-process MCP + HTTP tool servers, `transpile`, and the bound-agent **tool-grant** plumbing (`agent.tools` roster grant + `boundAgentTools` runtime param). All provider integration points are optional (`?:`/`?.`), so providers degrade cleanly. **Do not** touch provider subagent `tools` frontmatter (`utils/agent.ts`, `claude/agents/AgentStorage.ts`, `opencode/storage/*`) or skill grants — those are unrelated.

**Tech Stack:** TypeScript, Obsidian plugin API, Jest (unit + integration), ESLint, esbuild.

**Verification gate (run after every phase, hard gate at the end):**
```bash
npm run typecheck && npm run lint && npm run test && npm run build
```
